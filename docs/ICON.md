# App icon

## What ships today

`ios/BEFORE/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` —
1024×1024, generated by `ios/scripts/make-app-icon.mjs`.

```bash
make icon      # or: node ios/scripts/make-app-icon.mjs
```

A single burgundy **B** on the warm off-white background. No dependencies: the
script rasterises the letterform with supersampled anti-aliasing and writes the
PNG container by hand.

It is a placeholder a designer should replace. It is also a **real asset** — the
project builds and ships a legible icon today rather than a missing file.

## The concept

Spec §60: a strong letter **B**, or a minimalist typographic symbol derived from
one. No tiny text, nothing that dissolves at 40pt on a home screen.

| | |
| --- | --- |
| Background | `#FAF8F5` — the app's warm off-white, full bleed |
| Glyph | `#6E2639` — the burgundy accent |
| Height | 620 of 1024, optically centred |
| Stroke | 85 |
| Bowls | lower larger than upper, as in any real B |

The geometry is **derived, not eyeballed**: each bowl's inner radius is exactly
half its counter height, so the inner curve meets the bars tangentially instead
of leaving a notch, and the outer radius is inner + stroke, so each bowl spans
precisely from the outer edge of one bar to the next.

The first version enumerated the shapes by hand and produced malformed counters
that read as a "P" with a bite out of it. Deriving them fixed it.

## Replacing it

Drop a 1024×1024 PNG at the path above. Requirements:

- **No alpha channel.** iOS rejects transparency in app icons.
- **No rounded corners and no shadow.** iOS applies the mask itself; baking one
  in produces a double-rounded icon.
- **Full bleed.** The background must reach every edge.
- Test at 40pt. If the counters close up, thicken the background contrast or
  reduce the stroke — do not add detail.

Single-size is correct for Xcode 14+: one 1024 asset, with iOS deriving the rest.

## Dark and tinted variants

Not provided. The light icon reads well against both wallpapers because the
background is a warm off-white rather than pure white.

If they are wanted later, add `AppIcon-Dark.png` and `AppIcon-Tinted.png` and
extend `Contents.json` with `"appearances"` entries. The tinted variant must work
as a grayscale luminance mask, so a solid glyph on a solid background — which
this mark already is.
